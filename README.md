# Aprendiendo Hacking Ético desde Cero

Repositorio base para aprender hacking ético de forma progresiva con teoría y práctica.

## Estructura básica

```text
.
├── practicas/
│   └── README.md
└── teoria/
    └── README.md
```

## Cómo usar este repositorio

- Agrega contenido conceptual en `teoria/`.
- Agrega laboratorios, ejercicios y retos en `practicas/`.
- Mantén cada tema en archivos separados para crecer de forma ordenada.
